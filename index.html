Warcraft Rustcorder

Signed Flatpak repository for Linux (Wayland), plus Windows updates.

Automatically record and review World of Warcraft gameplay locally.

Install on Linux

curl -fsSL https://raw.githubusercontent.com/JohanWes/wow-rustcorder/main/install.sh | bash

Or add the remote and install directly:

flatpak remote-add --user --if-not-exists warcraft-rustcorder \
  https://johanwes.github.io/wow-rustcorder/index.flatpakrepo
flatpak install --user warcraft-rustcorder io.github.JohanWes.WarcraftRustcorder

Update

flatpak update --user

Installs of the old name (io.github.JohanWes.WarcraftRecorder) move to Warcraft Rustcorder on their next update, settings included.

Install on Windows

Download WarcraftRustcorder-<version>-setup.exe from the latest release and run it. The app checks for updates itself.

Commits are GPG-signed with key 8FAF1364A2686F0F. The public key is embedded in index.flatpakrepo, so flatpak remote-add configures verification for you.

Source, releases, and issues: github.com/JohanWes/wow-rustcorder
